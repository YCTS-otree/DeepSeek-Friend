# 标准源码包

这是 DeepSeek:Friend v1.8.2 的代码、锁文件、测试、初始 Prompt/Self 和文档快照，不含当前聊天、运行数据库、授权或已安装依赖。

从 README 的环境和首次部署步骤开始。需要 Node 24、Python 3.10+、自己的 API Key 和账号授权。当前仍保留 OTREE 的初始身份与固定可信 QQ 配置，作为实际源码；部署成自己的实例前请按需求明确调整并测试，不要仅改昵称。

`PACKAGE_MANIFEST.json` 可验证文件完整性，外部 CHECKSUMS 可验证 ZIP。架构与设计理念见 docs/architecture.md、docs/design-philosophy.md，融合见 docs/integration-guide.md。
