# Cognitive v3 验收与研究记录

版本 1.2.0；日期 2026-10-22；Windows / Node 24.19.0 / Python 3.10.11；项目独立 DSH 0.2.0-rc.2。按用户最后修正采用整个实例统一 Self 和记忆库，参与者只是来源信息。

## 自动化与真实环境的区别

- `npm run check`：JS 语法检查。
- `npm test`：84 项本机/Mock/原生装配测试，2 项需要显式授权环境的真实服务测试默认跳过。新增 33 项认知测试包含真实已安装 DSH SystemPrompt 注册器，不能把它们全部称为真实模型测试。
- Python 启动器：15 项单元/本地 HTTP/进程测试；本轮未修改布局，不重复进行无关 UI 改版。
- `npm run test:cognitive:live`：单独执行真实 DSH/模型用例，验证 SYS 中的 OTREE/小鲸鱼、同一 Session 热更新、兼容模型切换以及独立后台结构化推理。使用 3098、独立研究 home/data、已授权 API Key；不连接工作 DSH，不读取签名私钥，不接微信。
- 三日合成评估：真实模型处理两组不同的合成经历与模拟日期，生产校验与有界重试后 12/12 任务接受。A 保留 3 条记忆，B 保留 5 条；两组 Self 都保持版本 1。不同输入造成不同记忆，并不证明已经形成不同稳定人格。汇总见 cognitive-evaluation-summary.json；完整合成研究结果在 `.research/` 的评测文件中，不进入发布包。

初期小输出预算评测曾出现明确未完成的 JSON 请求；没有把它们算成成功。修复/适配包括：后台显式配置已由 DSH DeepSeek 源码确认的 reasoningEffort=off、保持 maxTokens 上限、已知失败上下文重试与收据、独立拒绝无效 Self 提案。未知请求结果仍保留原请求 ID。

## A–J 对照

| 用户场景 | 本轮验证 | 边界 |
| --- | --- | --- |
| A 空闲记忆 | 模拟时间：14 分钟不提取；交互结束后 16 分钟提取并立即落盘，等待中的前台阻止空闲判定 | 真实后台 DSH JSON 已验证；真实微信静置 15 分钟需用户验收 |
| B 跨日连续性 | 模拟日期、固定水位、跨日任务与混合召回、持续目标记录；原 Session 映射保留 | 未把模拟日期当成真实跨日生活 |
| C Dreaming No-op | 多日空反思，Self 记录/版本/投影内容和 mtime 不变；实际模型两组评测也未产生 Self 新版本 | 不奖励更频繁更新 |
| D 经历塑造行为 | 独立真实来源/可观察结果的验证、不同合成经历的模型提取；多个来源才能建立稳定特征 | 尚未证明真实数周行为倾向已经形成；需要长期人工复核 |
| E 纠正旧认识 | 更正条目退休旧记忆，旧认识停止有效注入，替换/撤回/回滚保持审计历史 | 证据存在不等于自然语言解释已被形式化证明 |
| F 重启/模型切换 | SQLite 重开和 request 恢复、同一真实 Session 热更新、真实兼容模型切换后持续身份存在 | 本轮未做真实 DSH 进程重启后再聊天或真实 compaction 操作；装配独立于聊天窗口已由原生测试和源码核实 |
| G 自我强化 | 纯助手自述、重复文本、自身 memory/self 工具输出不构成独立性格证据 | 实际行动可能受旧认识影响，仍须长期研究循环偏差 |
| H 权限隔离 | 越界字段、跨实例无来源 ID、注入文本、假引用拒绝；后台无工具；原 Shell/写入/MCP guard 回归 | 共享库有意不按用户分区，披露依赖模型判断，不能宣称存储隔离 |
| I Prompt 层级 | 实际 SystemPrompt 重新装配、原生数据变量不重扫模板、同 Session 实际 system/message 出现新版本 | P0/P1 为一个 system prompt 的分段；P2 为 user-role context，无原生四级优先级 |
| J 不同演化 | 独立实例固定底座的机制测试 + 两组真实模型合成研究，保存提案/拒绝/no-op 结果供人工检查 | 没有仅凭文风或情感强度给出人格/意识结论 |

## 待验证与限制

1. 数周/真实跨日运行、真实 compaction、真实重启后认知对话以及不同模型长期行为差异。
2. 共享记忆中的隐私判断、来源冲突与自然语言证据解释需要人工复核；规则检查不是完整 Prompt Injection/Memory Poisoning 的数学保证。
3. 哈希词项向量不是神经语义 Embedding；同义、隐喻和跨语言召回还需质量测试。原始公开事件索引/检索不包含 reasoning；大工具结果和后台输入按预算摘录，完整源日志仍由 DSH 管理。
4. 没有已核实的 DSH 原始日志逐条删除 API；认知删除明确不代表上游日志/提供方/外部备份已抹除。
5. 调度器随 Bridge 存活，关机/停服务时暂停；补执行可能额外消耗模型额度，TokenBudget 不代表账户账单硬上限。Linux 尚未实机运行。

没有把任何自然语言自我叙述解释为主观意识或真实情绪的证据。
