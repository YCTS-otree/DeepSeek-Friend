## 新增自动回归

- 固定 Flash，热更新 off/low/high/max 与每请求长度上限；拒绝累计 maxSteps 预算字段。
- 一轮多条显式消息、重复工具意图幂等、reasoning 与私有笔记不进入微信。
- 原生 stopping 续行无步数计数器；主动休息、暂停及新消息让出边界。
- 旧整轮时长阈值不取消持续思考。
- 图片独立消息入站、原生 image block、RPC 结果不明时相同请求/图片重试且只下载一次。
- 图片数量拒绝仍可靠落库、返回提示。
- 官方三种 AES key 编码、CDN 域名/跳转/大小限制、类型校验、固定上传身份与回执缓存。
- 无原因闹钟、重启持久、补执行一次、归档/暂停/繁忙时等待。
- 闹钟后主动消息仅复用真实合法联系人；缺失联系人拒绝；当前对象不被新联系人意外替换；撤销授权后阻止入队。
- 发送超时 unknown 后不换 ID、不自动再次发送。
- 测试独立 Self/记忆/聊天、消息只写本机、不能删除正式会话；测试 `/cancel` 不影响正式任务。
- 离线清空时若 DSH 仍监听则拒绝；忙碌测试后台整理时不并发清空。
- 显式消息完成后的记忆写入失败，可以从持久记录补回。
- 查看 SYS 精确替换原文和旧备份；测试查看不会读正式 Self。
- Web 选择会话清空旧聊天/思考/Prompt、忽略旧响应、保留已翻页记录、外部文本以 textContent 渲染。
- 原有账号锁、去重、游标事务、审批、澄清、Session 恢复、Self 证据/版本/回滚/no-op 与房间安全回归。

## 真实 DSH / Flash

使用既有 runtime，不安装另一套环境。API Key 仅由已有可信启动加载器传到测试子进程环境；没有打印/复制凭证，也不读取 DSH 的签名私钥。每次测试创建研究目录和临时 Session，结束停止自己创建的测试 DSH。

1. 实际模型路由 `deepseek-official/deepseek-flash`（DeepSeek-V41-Flash），没有 Pro 回退。
2. 同一 turn 实际调用两次 `weixin_send_message`，产生两个有序持久意图，再 `take_rest`。
3. 合成红色 PNG 作为 DSH 原生图片输入，实际消息工具回答包含红色。
4. low 思考模式中，不要求微信输出；同一 turn 至少产生两次 assistant/message，历史存在 `source.kind=friend-continuation` 的内部 next-step 信号。
5. 实际 reasoning 与私有笔记落库；只核对存在，不把思考正文写进测试终端日志。

实测期间发现并修复两个版本兼容问题：Preset 父 scope 的 allow:[] 会隐藏自身工具；agent.inject 只接受 UserMessage，不能塞 DeveloperMessage。已按真实原生行为实现，不将正文 DSML 标记解析成工具指令。

## 手机验收步骤

退出旧启动器后重新打开 start-web.bat。先发普通文本，再发图片并询问内容；要求她先后发两条独立消息。观察微信只收到显式消息，控制台「思考与闹钟」保存私有记录。在本机设置一分钟后的闹钟，允许她自主选择是否联系；不要求每次闹钟都说话。最后新建测试会话、发测试文本、清空测试，检查正式当前会话与历史仍保留。

任何 unknown 先核对手机记录，再按运维流程处理；不要用换 ID 重发来掩盖不确定投递。
