# v1.14.1 · MNN 系统应用首版

发布日期：2026-10-25。应用 DeepSeek:Friend **1.14.1**，集成 MNN **1.3.1**，独立 DSH **0.2.0-rc.2**。

这是项目以 MNN 作为正式记忆与上下文整理系统的首个应用发布基线，不把此前试接入版本重新命名或抹去。v1.10.0 继续作为旧架构封存版；中间实现、事故、失败样本及修复记录保留。

## 本版范围

- DSH 继续是唯一 Agent Runtime；MNN 负责统一证据记忆网络、分段 LLM Dreaming、Carryover 和 Adaptive Context Reconstruction（ACR），不另建 Agent、工具执行或模型调度框架。
- 微信、QQ 私聊及已授权群共享当前正式 Session、Self 和记忆。记忆不按联系人拆分，来源与受众仍逐条标明。
- Context Pressure Guardian 在 85% 软水位、95% 硬水位保护，安全维护后在原 Session 恢复。使用原生计数、官方词表、Provider 用量及输出预留；无法可靠计价或固定预算不足时拒绝，不降级到 Basic Compaction。
- 正式来源注册表与数据代际隔离。归档、未知、类型不匹配和废弃代际不进入前台或后台记忆摄入，LLM 返回后提交前再次核对。
- 没有新增真实经历时只推进水位，不重复调用 LLM 巩固旧笔记或重复生成目标。日常空闲提取不等于重建当前对话。
- 保留有来源、有预算的近期完整对话，避免只保留稀疏索引而损失表达连续性；诊断、生成检查点、推理和私密笔记不作为新的独立经历循环强化。
- 保留 SYS、初始 Self v0.1.0、当前 Self 与小房间；MNN 正式 Self 自动提交和互联网入口仍关闭。群白名单、工具审批和本机管理边界保持独立。

## 使用与升级

代码或发布标签不自动开启任何新能力。运行中的实例按已验证配置继续工作；本次更新发布文档，不更换正式 Session、不触发重新 Dreaming 或数据清理。

已有 MNN 实例先核对实际运行源码摘要、来源注册表和数据代际，不能直接拼接不同代际的库。首次部署参考 [集成与门禁](../mnn-integration.md)，大功能或外部边界扩大仍要求停服、完整 DSF 校验与操作者授权。失败不得开放；网页回滚保留三次独立且各至少 3 秒的确认。

维护文档里的 `clean_generation.py prepare --apply` 等命令具有破坏性，只记录此前明确授权的事故恢复，不是日常升级步骤。
